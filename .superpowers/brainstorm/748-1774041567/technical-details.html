Technical Details

Data source, architecture, and interaction specifics

Data Source

TMDB (The Movie Database) API — free, well-documented, has franchise/collection data

We'll pre-fetch and save as a static JSON file. Fields per movie:

  • title, release_date, vote_average, vote_count
  • budget, revenue, runtime
  • genres[], poster_path
  • belongs_to_collection — groups movies into franchises

~15-20 franchises, ~200-300 total movies. Static JSON, no server needed.

Interaction Specification

Interaction Trigger Effect
Brush timeline Click+drag on river Dominance chart + trajectory chart filter to brushed range with animated transition
Hover franchise line Mouseover on trajectory Selected line boldens, others fade to 10% opacity. Profile card updates.

Dynamic filters Dropdowns + slider All 4 panels animate to new filtered state simultaneously

Animation Spec

  • Filter transitions: 600ms ease-in-out — rivers morph, bars slide, lines redraw
  • Hover highlights: 200ms fade for non-selected elements
  • Narrative pulse: 1s pulse animation on highlighted data points when insight changes
  • Initial load: Rivers draw in left-to-right with staggered 100ms delay per franchise
  • Profile card flip: 300ms scale transform when switching between franchise/movie views
