Three Approaches for Franchise Explorer

Interactive D3 dashboard comparing movie franchises — pick the direction that feels right

A

Timeline River

Main view: A horizontal timeline (1970–2025) where each franchise is a "river" — a horizontal band whose height encodes box office revenue per entry. Movies appear as dots along the river, colored by rating.

Supporting panels:

  • Franchise Comparison Bar Chart — total revenue, avg rating, # of entries side-by-side
  • Detail Card — click a movie dot to see poster, budget, revenue, rating, cast

Interactions: Brush a year range on the timeline → bars and stats update. Filter by genre/franchise via dropdowns. Animated transitions when filters change. Narrative annotations highlight key moments ("MCU Phase 3 peak").

Pros

  • Strong temporal narrative
  • Natural brushing target
  • Visually distinctive

Cons

  • River layout is complex to implement
  • Can get cluttered with many franchises
B

Scatter + Linked Dashboard

Main view: An animated scatter plot with configurable axes (budget vs revenue, sequel # vs rating, year vs revenue, etc.). Each dot is a movie, colored by franchise, sized by box office.

Supporting panels:

  • Franchise Trajectory Line Chart — shows selected franchise's rating/revenue across sequels as a connected line
  • Aggregate Stats Panel — bar chart comparing franchises on chosen metric

Interactions: Dynamic dropdowns change scatter axes with smooth animated transitions. Brush on scatter → highlights in trajectory chart. Click franchise in bar chart → filters scatter. Annotation callouts for outliers.

Pros

  • Flexible — many stories from one view
  • Axis-switching animations are impressive
  • Scatter is forgiving with varied data

Cons

  • Scatter plots can feel generic
  • Need good axis combos to tell stories
C

Franchise Showdown Arena

Main view: A "slope chart" / parallel coordinates view — each franchise is a line connecting its entries across sequel number (x-axis), with y-axis showing rating or revenue. Lines rise and fall, visually showing sequel fatigue or resilience.

Supporting panels:

  • Stacked Timeline — area chart showing franchise box office share over time
  • Franchise Radar/Profile Card — spider chart comparing a selected franchise on multiple metrics

Interactions: Hover a franchise line → all others dim, detail card appears. Brush a sequel range on the slope chart → timeline updates. Filter by decade/genre. Annotations mark franchise milestones.

Pros

  • Directly shows sequel fatigue patterns
  • Slope chart is visually compelling
  • Strong narrative potential

Cons

  • Franchises have different # of entries — uneven lines
  • Radar charts can be hard to read
